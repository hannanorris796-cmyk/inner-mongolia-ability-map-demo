# 内蒙古专业群能力图谱平台

基于参考页面和《静态 Demo 产品需求文档_PRD_v0.1.md》制作的可点击静态演示。岗位、能力、课程、方案、企业需求和报告共用统一的本地演示数据。

## 本地启动

需要安装 Python 3。进入此目录后运行：

```powershell
python -m http.server 4173
```

浏览器打开 <http://localhost:4173> 即可进入 Demo。也可使用其他静态文件服务器直接托管此目录，无需安装前端依赖。

## Demo 主线

总览 → 产业链全景 → 企业与岗位 → 岗位溯源 → 能力四维映射 → 课程岗位关联 → 课程标准；另可演示培养方案创建和版本对比、企业需求填报与模拟审核、供需看板、报告生成编辑和发布。

所有数据保存在浏览器本地存储。管理员菜单可重置演示数据。预测、AI生成、审核和资料解析均使用固定模拟结果，不会调用后端或模型服务。导出功能会生成本地演示文件。

完整需求范围见 [静态 Demo 产品需求文档 v0.1](docs/静态Demo产品需求文档_PRD_v0.1.md)。
